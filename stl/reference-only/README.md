# Reference only — omit from the active build

- `p2-spring-support-plate.stl` belongs to the CNC swing-arm alternative. It overlaps the selected printed P8 arm.
- `4020-part-cooling-duct.stl` is the original rear-blower duct. The TAP build uses the new top-blower duct.
- `two-station-dock.stl` is the superseded 30 mm-pitch, low-rail dock. Its loaded approach interferes with a neighboring tool. Do not print it for this build.
- `old-2020-rail-fit-coupon.stl` matches that superseded saddle, not the raised-rail module.

These files are retained for traceability, not as fallback installation options.
