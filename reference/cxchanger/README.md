# CxChanger source references

These files document the original [CxChanger project by cx330-TXY](https://github.com/cx330-TXY/CxChanger). They are historical references for M3DP Changer, not the current print or commissioning instructions.

| Reference | Purpose |
|---|---|
| [Original README](README-original.md) | Original assembly instructions cited by the printed adaptation |
| [English README](README-English.md) | WheelsTheCat's translation, with its coordinate diagram in `images/` |
| `klipper/` | Original configuration examples; `printer.cfg` and `toolchange.cfg` are used by the offline regression tests |

The original configurations are unchanged from `upstream-2026-09-29` (`f5e88ce87f0204d034d888ffd2aa6d259816f5d3`). Only the local links in the two READMEs were adjusted when these files moved. Preserve the original credits and the repository's [GPLv3 license](../../LICENSE).

Use the [M3DP print guide](../../stl/README.md), [illustrated assembly guide](../../m3dp/cad/printed-6.11/assembly-guide/README.md) and [current Klipper guide](../../m3dp/klipper/README.md) for this build. Retained CAD sources are described in the [CAD layout](../../m3dp/cad/README.md).

Unused upstream downloads and duplicate exports were removed from the working tree, with their history intact. See the [repository layout and recovery notes](../../docs/REPOSITORY-LAYOUT.md).
